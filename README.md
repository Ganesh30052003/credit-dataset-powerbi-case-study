# credit-dataset-powerbi-case-study
# 📊 Credit Dataset Case Study – Power BI  

## 📌 Project Overview  
This project explores the **German Bank Credit Dataset (credit.csv)** using **Power BI Desktop & Power Query Editor**.  
The goal was to solve real-world style **case study questions**, perform data transformations, and visualize insights using **tables in the Power BI canvas**.  

Through this exercise, I gained hands-on experience in **data cleaning, aggregation, filtering, and visualization** using Power BI.  

---

## 🗂️ Dataset  
- **Name:** Credit Dataset (German Bank Credit Data)  
- **File:** `credit.csv`  
- **Columns include:** loan purpose, credit history, personal status, employment length, saving balance, months loan duration, job type, housing, etc.  

> ⚠️ Note: If the dataset is not shareable, you can download it from [UCI Repository](https://archive.ics.uci.edu/ml/datasets/statlog+(german+credit+data))  

---

## 📝 Case Study Questions Solved  

1️⃣ Find the loan purpose with the **highest and lowest number of customers**  
2️⃣ Calculate the **average loan amount** by personal status  
3️⃣ Classify **customers as defaulters and non-defaulters**  
4️⃣ Find the **credit history** for Single Male customers who have taken loans for cars (New and Old)  
5️⃣ Find the **Minimum and Maximum Loan Amount** for distinct employment lengths  
6️⃣ Find the **Maximum Months Loan Duration** for distinct credit history only for single male customers with car loans  
7️⃣ Count the **number of customers with saving balance > 1000 DM**  
8️⃣ Compare the number of customers **staying in their own house vs renting** for skilled employees
